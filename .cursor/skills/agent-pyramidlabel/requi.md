用户说「开始做金字塔预标注 / pyramid label / 小样本扩标注」时，Agent 按本需求执行。  
正式 Skill：`.cursor/skills/agent-pyramidlabel/SKILL.md`（2026-07-24 已生成；人工/写回仍占位）。

---

## 0 目标与直觉

  - **场景**：一个数据集共约 \(N\) 张图（例：1 万），当前仅有少量金标 \(n_0\)（例：100）已标注；希望**多轮迭代**把标注扩到全量。
  - **核心思想**：用「已标注集合」训一个**多类别**检测模型 → 对下一批未标注图做伪标签（只留高 conf）→ 并入训练集 → 再训 → 再扩，直至覆盖全量或达到约定停止条件。
  - **与 automerge 区别**：
    - automerge：按**基类**拆成 M 个单类模型，给「缺该类」的任务子集补标。
    - pyramid：在**同一数据集**内，按**样本量金字塔**从小到大扩标；模型可为**多类**，不按类拆模型（除非用户另要求）。

  **(2)** 确认目录是否为 YOLO 可用结构（参考 `standard-dataset_merge`）：至少含 `images/`；已标样本有 `labels/`（或 `jsons/` 可转）。

  **(3)** 统计并与用户确认：

  | 项 | 含义 | 示例 |
  | --- | --- | --- |
  | \(N\) | 全量图像数 | 10000 |
  | \(n_0\) | 当前已有正式标注的图像数（金标种子） | 100 |
  | \(U\) | 未标注池 \(N - n_0\) | 9900 |
  | 类别 | 种子标签中的类别列表 | car, person, … |

  **(4)** 与用户确认扩标日程（金字塔台阶）。**参考比例 = 每轮从全量中新采的份额**（不是「累计已标注占比」）；各档之和为 100%：

  | 轮次 \(k\) | 本轮新增占比 \(p_k\)（相对 \(N\)） | 本轮新采数量 \(|S_k|\) | 本轮训练用已标集合 |
  | --- | --- | --- | --- |
  | 0 | — | 0 | 仅金标种子 \(L_0\)（\(n_0\) 张） |
  | 1 | **5%** | \(\approx 0.05 N\) | 训 \(L_0\) → 伪标 \(S_1\) → 得到 \(A_1\) |
  | 2 | **10%** | \(\approx 0.10 N\) | 训 \(L_1=L_0\cup A_1\) → 伪标 \(S_2\) |
  | 3 | **15%** | \(\approx 0.15 N\) | 训 \(L_2=L_1\cup A_2\) → 伪标 \(S_3\) |
  | 4 | **30%** | \(\approx 0.30 N\) | 训 \(L_3\) → 伪标 \(S_4\) |
  | 5 | **40%** | \(\approx 0.40 N\) | 训 \(L_4\) → 伪标 \(S_5\) |

  - **关键**：\(5\%+10\%+15\%+30\%+40\% = 100\%\)，表示未标注部分按这五档**分批采完**；每一轮训练都带上**截至上轮已采纳的全部标签**（种子 + 历史伪标），不是只用本轮新数据。
  - 例：\(N=10000,\ n_0=100\)  
    - 轮1：用 100 金标训练 → 新采约 500 张做伪标 → 采纳 \(A_1\)  
    - 轮2：用 \(100+|A_1|\) 训练 → 再新采约 1000 张  
    - 轮3：再 +1500；轮4 +3000；轮5 +4000  
    - 累计新采约 10000；若种子已占部分 stem，采样时跳过种子，末轮对 \(U\) 剩余扫尾。
  - **调整原则**（Agent 可微调，开跑前贴实际 \(S_k\) 表确认）：
    - 百分比默认相对全量 \(N\)；若 \(n_0\) 不可忽略，也可改为相对未标注池 \(U\) 按同比例拆分（需在确认表中写明）。
    - 单轮过小可与邻档合并；过大可拆档；末轮吃掉 \(U\) 剩余。

  **(5)** 与用户确认阈值与策略（已拍板）：

  | 项 | 默认 | 说明 |
  | --- | --- | --- |
  | pass1 `conf` | **`>= 0.35`** | 本轮采样 \(S_k\) 初标，用于出 check 候选 |
  | NMS `iou` | **`0.45`** | pass1/pass2 推理均传；抑叠框（越低越狠） |
  | check 抽检 | **优先中低 conf**（如 `0.35–0.5`） | 默认约 `\|S_k\|×20%`（例：5 抽 3）；images+jsons，暂停人审 |
  | 校验模型 | **人审后必训** | 用 \(L_{k-1}\cup\) 本轮 check 金标，训 `Model-round-k-check` |
  | pass2 `conf_keep` | **`>= 0.5`** | 校验模型只标 \(S_k\) 中**未进 check** 的剩余图；过线并入，空检回 U |
  | 人工 check | **默认开启** | 用户明确「跳过人工/全自动」才关闭 |
  | 种子金标 | **永不被伪标签覆盖** | 正式 `labels/` 种子只读 |
  | 热启动 | **下轮用本轮校验模型 `best.pt`** | 第 1 轮主模型用公共预训练；`Model-round-(k+1)` 热启 `Model-round-k-check` |

## 3 迭代工作流（每轮 \(k = 1, 2, \ldots\)）

  记 \(L_{k-1}\) = 截至上轮已采纳的全部已标（种子 + 历史伪标/人审）。  
  记 \(U_{k-1}\) = 仍未采纳的图像池。  
  记 \(S_k\) = 本轮从 \(U\) 新采的待标集合。

  ### 3.1 选样

  **(1)** 从 \(U_{k-1}\) 随机无放回抽 \(S_k\)，\(|S_k|\approx p_k\times N\)（或相对 \(U\)；末轮取剩余全部）。

  ### 3.2 主模型训练

  **(1)** 用 \(L_{k-1}\) 训 `Model-round-k`（\(k=1\) 公共预训练；\(k\ge 2\) **热启上轮校验模型** `Model-round-(k-1)-check`）。

  ### 3.3 pass1 初标 + check

  **(1)** 用 `Model-round-k` 对整份 \(S_k\) 推理：NMS **`iou=0.45`**，保留 **`conf >= 0.35`** 的框（写入 pass1 目录或供抽 check）。

  **(2)** 从 \(S_k\) 抽 check（默认约 20%）：**优先带中低 conf 框的图**（band 如 `[0.35, 0.5]`），导出 `pre/round-k/check/`（images 软链 + LabelMe jsons）。

  **(3)** **暂停等人审**；人审改框后的 check 视为本轮金标 \(C_k\)。

  ### 3.4 校验模型 + pass2

  **(1)** 用 \(L_{k-1}\cup C_k\) 训 `Model-round-k-check`（热启本轮 `Model-round-k`）。

  **(2)** 对剩余 \(R_k = S_k\setminus C_k\)，用校验模型伪标：NMS **`iou=0.45`**，仅保留 **`conf >= 0.5`** → 得到自动采纳 \(R_k^{\mathrm{keep}}\)；空检退回 \(U\)。

  **(3)** 本轮采纳 \(A_k = C_k \cup R_k^{\mathrm{keep}}\)；\(L_k = L_{k-1}\cup A_k\)；\(U_k = U_{k-1}\setminus A_k\)。  
  **默认不写**正式 `labels/`。

  ### 3.5 小例子（\(n_0=10\)，待标 \(U=100\)，本轮 \(|S_1|=5\)，check=3）

    ```markdown
    Round 1
    1. 用 10 张种子训 Model-round-1
    2. 从 100 抽 5 张；pass1 conf>=0.35 iou=0.45 初标
    3. 抽 3 张 check（优先 conf 0.35–0.5）→ 人工改框/确认 → C1
    4. 用 10+3=13 训 Model-round-1-check
    5. 校验模型对剩余 2 张 pass2 conf>=0.5 iou=0.45
    6. 若 2 张都过线：L1=10+5=15，U=95
       （剩余若空检则回 U，L1=10+|C1|+过线数）

    Round 2
    1. 用 L1=15 训 Model-round-2（热启 Model-round-1-check）
    2. 再抽下一批… 重复 pass1 → check 人审 → 校验模型 → pass2
    ```

  ### 3.6 循环条件

  - \(U_k\) 为空或计划轮次全部完成 → 进入交付。
  - 连续两轮采纳过低 → 暂停询问（降 conf / 改采样 / 停止）。
