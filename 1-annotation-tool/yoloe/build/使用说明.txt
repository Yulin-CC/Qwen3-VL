Grounding 检验工具（Windows 绿色便携包）
========================================

一、怎么用
  1. 解压整个文件夹到任意位置（不要只解压出单个文件）
  2. 双击「start.bat」
  3. 浏览器会打开 http://localhost:8090
     （若未自动打开，请手动访问该地址）
  4. 在页面点击「选择图像数据集」，选含 images/ 与标签目录的数据根目录
  5. 用完后关闭黑色控制台窗口即可退出（会自动释放端口）

二、不需要
  - 不必安装 Python / conda / Docker
  - 不必改系统环境变量
  - 一般不需要管理员权限

三、修改远程大模型地址（可选）
  用记事本打开：
    yoloe\1-start_review.bat
  顶部可改：
    set "VLLM_BASE_URL=http://你的服务器:端口/v1"
    set "VLLM_MODEL=模型名"
  保存后再双击「start.bat」

四、快捷键（页面焦点不在输入框时）
  A / D     上一张 / 下一张图
  W / S     上一条 / 下一条 caption
  Ctrl+滚轮 缩放图像

五、更新
  需要新版本时，向维护者索取新的 zip，解压覆盖即可。
