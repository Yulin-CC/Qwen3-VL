# Qwen3-VL 模型结构

整体是经典的 **视觉编码器 + 连接层 + 语言模型** 三段式架构，每一块都有针对性升级。

## 整体结构

`
输入图片/视频/文字
       │
       ▼
┌──────────────────┐
│  Vision Encoder  │  ViT（视觉 Transformer）
│  (model.visual)  │  → 提取视觉特征 Patch
└────────┬─────────┘
         │ 多层特征（DeepStack 融合）
         ▼
┌──────────────────┐
│  MLP Merger      │  视觉-语言连接层（Projector）
│  (visual.merger) │  → 将视觉 token 压缩、对齐到 LLM 维度
└────────┬─────────┘
         │ 视觉 tokens 插入文本序列
         ▼
┌──────────────────────────────┐
│  Language Model              │  Qwen3 LLM 主干（Dense 或 MoE）
│  (model.language_model)      │  → 统一处理文本 + 视觉 tokens
│  + lm_head                   │
└──────────────────────────────┘
         │
         ▼
      文字输出
`

## 三大核心创新

### 1. Interleaved-MRoPE（交错式多模态旋转位置编码）

这是 Qwen3-VL 相比前代最重要的升级，在 
ope2d.py 中实现：

- 普通 RoPE：每个 token 只有 **1维** 位置编号
- MRoPE：每个 token 有 **3维** 位置编号 [时间 t, 高度 h, 宽度 w]
- 文本 token：三维相同，退化为普通 1D 位置编码
- 图片 token：	=0，h/w 按 patch 网格分配（2D 空间位置）
- 视频 token：	 编码真实时间戳（秒），h/w 编码空间位置

`
Qwen2-VL：  视频用帧序号 0,1,2... 编时间
Qwen2.5-VL：视频用绝对时间（秒×fps）编时间
Qwen3-VL：  视频用真实时间戳（Text-Timestamp Alignment）编时间
             每帧独立作为 1 个时间步，timestamp 写入文本侧
`

代码里三个版本分别对应 get_rope_index_2 / get_rope_index_25 / get_rope_index_3。

### 2. DeepStack（多层特征融合）

- 不只取 ViT 最后一层的输出，而是**融合多个中间层的特征**
- 捕获从低级纹理到高级语义的多尺度视觉信息
- 由 isual.merger（MLP Projector）负责融合压缩后传给 LLM
- 这是 Qwen3-VL OCR 和细粒度识别能力提升的关键

### 3. Text-Timestamp Alignment（文字-时间戳对齐）

- Qwen2.5-VL 用 T-RoPE（时间旋转位置编码）编码视频时间
- Qwen3-VL 改为在文本侧插入真实时间戳 token，如：

`
<t=0.0s> <vision_start> [帧1特征] <vision_end>
<t=1.5s> <vision_start> [帧2特征] <vision_end>
`

- 让模型能做到**秒级精确的视频事件定位**

## 两种规格

| 类型 | 代表模型 | LLM 主干 |
|------|---------|---------|
| **Dense（密集）** | 2B / 4B / 8B / 32B | 标准 Transformer Decoder |
| **MoE（混合专家）** | 30B-A3B / 235B-A22B | 稀疏 MoE，激活参数远小于总参数 |

	rain.py 中通过路径名里是否有字母 a（如 30B-A3B）自动区分这两种结构。

## 微调时可控的三个模块

`python
tune_mm_vision = True/False   # ViT 视觉编码器（最重，通常冻结）
tune_mm_mlp    = True/False   # MLP Merger 连接层（中等）
tune_mm_llm    = True/False   # LLM 主干（最大，也可选 LoRA）
`

训练时通过 config/default.yaml 控制这三个开关，实现从「只训连接层」到「全量微调」的灵活组合。
